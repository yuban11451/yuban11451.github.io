# dart的布尔类型 - bool

场景 我们需要一个属性来表示当前状态为真（ture）或者假（false）的时候 需要用上bool关键词声明

需求 声明自己是否完成家庭作业

语法 bool 属性名 = ture 或者false

```
void main(){
    bool finish = false;
    print("我目前的作业状态$finish);
    finish = ture;
    print("我目前的作业状态$finish);
}
```
